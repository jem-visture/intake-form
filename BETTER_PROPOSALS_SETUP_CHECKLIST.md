# Better Proposals Connection Checklist

## Provide or confirm these items

- [ ] Current Better Proposals plan: Trial, Starter, Premium, or Enterprise.
- [ ] Confirmation that API access works. Premium or Enterprise is required after the trial.
- [ ] A Better Proposals API token generated by an administrator or designated integration user.
- [ ] The API token is stored server-side in `.env` or a secret manager; it is not pasted into chat.
- [ ] Template ID `744153` is the intended Visture master proposal template.
- [ ] `BP_TEMPLATE_ID=744153` is configured server-side; template selection is not exposed in the intake form.
- [ ] Visture brand selection.
- [ ] Visture cover selection, if a separate cover is used.
- [ ] Document type, normally `Proposal`.
- [ ] Currency, normally `CAD`.
- [ ] GST setting, label, and percentage.
- [ ] A Digital Signature block inside the template.
- [ ] The entered test recipient is marked eligible or required to sign.
- [ ] JG's Better Proposals user email.
- [ ] Confirmation that JG can access and review API-created drafts.
- [ ] On Enterprise, the creator or automation user is configured to require Sending Approval from JG.
- [ ] Confirmation of which user owns proposals created with the API token.
- [ ] Sending-domain setup and sender identity for the eventual customer email.

## Screenshots that are safe and useful

Screenshots may be provided with any token or secret fully redacted:

- [ ] Account plan or billing page.
- [ ] Settings > Integrations page.
- [ ] Template list showing the intended Visture template.
- [ ] Settings > Setup > Custom Merge Tags.

## Do not share

- [ ] Do not paste the API token into ChatGPT.
- [ ] Do not place the token in the HTML page.
- [ ] Do not commit `.env` to source control.
- [ ] Confirm the entered recipient carefully before creating the draft and before any later manual send.
