Enterprise approval path

  1. The creator opens the API-created draft and selects Request Approval.
  2. JG opens the item under Documents > Pending and approves or denies it.
  3. After approval, an authorized user opens the approved item and clicks Send Document.
  4. The entered recipient receives the proposal and completes the signature test.

Premium fallback

  1. The API creates the draft.
  2. JG reviews it manually; Premium does not include native Manager Approvals.
  3. JG or an authorized user clicks Send Document.
  4. Zapier can observe sent, opened, and signed events for GoHighLevel updates.
